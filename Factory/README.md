# FactorySimulator

Web 版工廠模擬器 MVP（可在瀏覽器直接開啟）。

## 功能

- 自由設定地圖格數（寬、高）
- 編輯格子：空地、路徑、入口、出口
- 基礎模擬：入口生成物件，沿路徑移動至出口
- 控制：開始、暫停、重置、速度調整

## 如何執行

1. 直接用瀏覽器開啟 `index.html`
2. 建議使用 VS Code / Cursor Live Server 或任何靜態伺服器

## 操作流程

1. 設定寬高並點「重建地圖」
2. 用「路徑」工具先畫出運輸路線
3. 放置至少一個入口與一個出口
4. 點「開始」進行模擬

## 後續可擴充

- 機器格（加工、延遲、配方）
- 方向型輸送帶（非單純鄰格移動）
- 多種物品與吞吐量統計圖表
